# «Кто это?» — игра для компании (сауна, 31.10.2026)

Идея друга (голосовое 29.10): каждый с телефона пишет о себе малоизвестный факт, потом все угадывают автора;
автору голосовать за свой факт нельзя. Рассчитано на ~20 человек.

## Запуск

```
node server.js            # порт 8080, или PORT=8090 node server.js
```

Без зависимостей, нужен только Node. Состояние комнат — в памяти и копией в `data/rooms.json`
(переживает перезапуск сервера).

## Адреса

- `/host` — пульт ведущего: меню (режим, рубрика, число вопросов), QR-код для входа, кнопки хода игры.
  Работает и с телефона. Токен ведущего хранится в браузере — пульт открывать на одном устройстве.
- `/?room=1234` — телефон игрока (по QR-коду).
- `/1234` — экран комнаты только для показа, без кнопок: на ТВ, ноутбук по HDMI и т. п.
  Большой экран не обязателен — вопрос и варианты видны на каждом телефоне.

## Режимы

- **Кто это?** — рубрики: Микс (рубрику каждого факта выбирает игрок), Страхи, Ни разу не делал,
  Тайный талант, Странная привычка. Ответы: 4 варианта или все игроки (сложно). До 3 фактов на человека.
- **Две правды и ложь** — каждый пишет три утверждения и отмечает ложь; остальные ищут ложь.

Вопросов в раунде: 10 / 20 / 30 / все. Сначала берётся по одному факту от каждого, сыгранное
в следующем раунде не повторяется; «с чистого листа» стирает всё написанное.

## Очки

Верно — 500 + до 500 за скорость (таймер 25 с). Автор получает 1000 × доля не угадавших.
Вопрос закрывается сам, когда ответили все или кончилось время. В итогах — топ-10
и «самый загадочный» (кого угадывали реже всех).
